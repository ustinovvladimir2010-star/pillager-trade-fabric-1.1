# Pillager Trade & Contracts — Fabric 1.20.1

Исходный проект мода для Minecraft 1.20.1 Fabric.

## Что уже заложено в этой версии
- ПКМ по поборнику открывает отдельное торговое окно.
- Индивидуальная репутация и специализация сохраняются в данных мира.
- Начальный ассортимент ограничен базовыми товарами.
- Покупка за изумруды.
- Базовая команда найма на один игровой день (пока только контракт/флаг найма).
- Основа для заказов, поручений и ежедневного обновления состояния.
- Предметы адресуются через registry ID, поэтому архитектура допускает предметы из других модов.

## Важно: статус реализации
Это **исходный прототип 0.1.0**, а не проверенный готовый релизный `.jar`.
В этой сборке ещё не реализованы полностью:
- реальное следование и боевой AI нанятого охранника;
- полноценная доставка заказанных предметов и выдача наград за поручения;
- полноценное динамическое сканирование всех модовых предметов и балансировка редкости;
- интерфейс выбора предмета из реестра, прокрутка каталога и полноценная механика торга;
- расширенная система прогрессии по дням/репутации.

## Сборка
Нужны JDK 17 (или совместимая среда) и Gradle.
В корне проекта выполните:

```bash
gradle build
```

Готовый jar появится в `build/libs/`.

## Установка
Скопируйте jar в папку `mods` вместе с Fabric API. Minecraft должен быть версии 1.20.1 Fabric.

## Настройки
Баланс и параметры пока находятся в исходном коде. Отдельный конфигурационный экран/файл будет добавлен в следующих версиях.
